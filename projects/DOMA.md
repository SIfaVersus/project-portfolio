# DOMA — Real Estate Discovery Platform

**Category:** PropTech · Digital Customer Experience  
**Status:** Functional Prototype  
**Year:** 2026

## Overview

DOMA is a real estate discovery platform designed to make property exploration more intuitive, visually engaging and user-friendly.

The project focuses on high-end property presentation, architectural aesthetics and a streamlined digital customer experience.

## Key Features

- Property discovery and search
- Dynamic property filtering
- Detailed property listings
- Property enquiry forms
- Viewing scheduling workflows
- Property listing submission requests
- Responsive, user-focused interface

## Technology Stack

**Framework:** Next.js  
**Frontend:** React, TypeScript  
**Styling:** Tailwind CSS  
**Runtime & Package Manager:** Bun

## Development Status

DOMA has reached the functional prototype stage.

The project demonstrates the core property discovery experience and its main user interaction workflows. It is not presented as a commercially launched platform.
