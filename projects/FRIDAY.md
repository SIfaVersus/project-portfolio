# FRIDAY — Personal AI Assistant

**Category:** Artificial Intelligence · Personal Productivity  
**Status:** In Active Development  
**Year:** 2026 – Present

## Overview

FRIDAY is a personal AI assistant for Windows, designed to operate locally without depending on cloud-based AI services.

The project explores how large language models and voice technologies can be combined into a unified desktop experience.

## Key Features

- Local large language model (LLM) integration
- Conversational AI interface
- Speech-to-text transcription
- Text-to-speech voice responses
- Desktop application for Windows
- Local-first AI architecture

## Technology Stack

**Desktop & UI:** Electron, React, TypeScript, Vite  
**LLM Runtime:** llama.cpp  
**Language Model:** Qwen3  
**Speech Recognition:** Whisper.cpp  
**Speech Synthesis:** Piper
