# ROAVIA — Travel Planning Platform

**Category:** TravelTech · Digital Customer Experience  
**Status:** Functional Prototype  
**Year:** 2026

## Overview

ROAVIA is a personalised travel planning platform designed to help users discover destinations, explore points of interest and organise their trips in one digital environment.

The project focuses on intuitive trip planning, location discovery and a user-friendly travel experience.

## Key Features

- Destination discovery and exploration
- Personalised travel planning
- Trip and itinerary management
- Point-of-interest discovery through Google Places API
- Saving locations for future trips
- User preference management
- Responsive user interface

## Technology Stack

**Framework:** Next.js  
**Frontend:** React, TypeScript  
**Styling:** Tailwind CSS  
**Runtime & Package Manager:** Bun  
**External API:** Google Places API

## Development Status

ROAVIA has reached the functional prototype stage.

The project demonstrates the core travel planning experience, including destination discovery, location management and integration with Google Places API.

It is not presented as a commercially launched travel service.
